## Roadmap
1. Доработать JWT
2. Добавить поддержку OpenTelemetry
3. Добавить поддержку бинарных данных в запросе `POST https://{{host}}/channels/:channel/messages`
4. Создать пример JS-приложения чата с каналом присутствия (`Presence`)
5. Добавить получение списка присутствующих (`SYNC`) при подключении к каналу
6. Добавить клиентские служебные события (`whisper`)
7. Реализовать кластерный Presence и совместимый с Ably Occupancy (по [документу](./docs/presence-occupancy.md))
8. Подготовить доменные типы и `PresenceStore`, вынести текущую локальную логику в единый контракт с тестами
9. Ввести проверку прав на возможности, сравнение запрошенных и фактических режимов, модель авторитетного присоединения
10. Ввести Redis-модель Presence/Occupancy: ключи, Lua-переходы, защиту от повторов, версии изменений, устойчивую очередь событий, guest-shards и список «грязных» каналов
11. Добавить событие изменений присутствия и упорядоченную рассылку по всем узлам
12. Перевести `ENTER`/`UPDATE`/`LEAVE`/`DETACH`/отключение на общий store и убрать прямые локальные рассылки
13. Сделать барьер при присоединении, `channelSerial`, восстановление после пропуска по версии
14. Добавить поколение узла, обновление аренды, защиту от чужих поколений и уборку просроченных записей
15. Добавить 6 метрик Occupancy, учёт гостей через guest-shards и локальное сглаживание частоты обновлений
16. Реализовать политику гостей, проверку прав токенов и отдельный путь выдачи токенов для PHP/SDK
